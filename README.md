# Oni in the Browser

An unofficial, work-in-progress WebAssembly port of Oni's original C game engine,
based on modified [OniARM64](https://github.com/andiyar/OniARM64) source. The game
runs entirely in your browser using original game resources, not a video stream
or an Oni-inspired recreation.

This repository contains the deployable website, compiled engine, game resources
and converted intro/outro movies for static hosting with GitHub Pages.

## Play

Open the published site, choose which resources to load, and click **Run original
Oni engine**. Use **Capture mouse** for mouse look and **Fullscreen** for fullscreen
play. Saves stay in your browser; **Download save** exports a backup.

The port is not yet verified as a complete one-to-one replacement: full campaign
playability and audiovisual fidelity still need testing.
